# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

Hyprland 0.55+ Lua configuration for a dual-monitor setup (CachyOS, NVIDIA). Entry point is `hyprland.lua`; old `hyprland.conf` is superseded.

## Applying Changes

```bash
hyprctl reload                   # reload hyprland.lua and all required modules
hyprctl keyword <key> <value>    # live-patch a single value without reload
hyprctl monitors -j              # inspect current monitor state + color management
hyprctl clients                  # list windows with class/title for rule writing
```

Screenshot script (standalone):
```bash
lua5.4 ~/.config/hypr/scripts/screenshot.lua
```

## File Structure

```
hyprland.lua          # Entry point — only require() calls
globals.lua           # SSOT: mainMod, terminal, browser, sink IDs, wallpaper path

core/
  env.lua             # All hl.env() — NVIDIA/Wayland/fcitx5/locale/cursor
  display.lua         # hl.monitor() x2, misc, render, dwindle
  input.lua           # input (keyboard/touchpad), cursor
  autostart.lua       # hl.on("hyprland.start") + hyprshade on reload; also loads the
                      # imecaret plugin (~/.config/quickshell/hypr-plugin/imecaret —
                      # rebuild with `make` there after every Hyprland update)

ui/
  theme.lua           # Colors (local C table), general, decoration (blur/shadow);
                      # border/shadow colours come from qs_theme.lua when it says enabled
  qs_theme.lua        # GENERATED by ~/.config/quickshell/scripts/theme-sync.py from the
                      # current Quickshell theme — don't edit; `[sync] hyprland = false` in
                      # ~/.config/quickshell/config/shell.conf restores the Y2K palette
  animations.lua      # hl.curve() definitions + hl.animation() calls
  rules.lua           # hl.window_rule() — all float/pin/center/size rules

binds/
  dispatchers.lua     # App launches, media keys, system commands
  wm.lua              # Window close/float, focus, workspace switch/move
  submaps.lua         # resize submap (ALT+W to enter, Escape to exit)

scripts/
  screenshot.lua      # Replaces screenshot.sh; run by dispatchers.lua
```

## Lua API Quick Reference (0.55)

```lua
hl.config({ section = { key = value } })
hl.monitor({ output = "desc:...", mode = "2560x1440@100", ... })
hl.env("KEY", "value")
hl.on("hyprland.start", function() hl.exec_cmd("waybar") end)
hl.bind("SUPER + Q", hl.dsp.window.close())
hl.bind("XF86AudioMute", hl.dsp.exec_cmd("wpctl ..."), { locked = true })
hl.bind("SUPER + mouse:272", hl.dsp.window.drag(), { mouse = true })
hl.curve("name", { type = "bezier", points = { {x1,y1}, {x2,y2} } })
hl.animation({ leaf = "windows", enabled = true, speed = 5, bezier = "name" })
hl.window_rule({ name = "id", match = { class = "^regex$" }, float = true })
hl.submap_bind("mapname", "key", hl.dsp...)   -- binds inside a submap
```

Bind option flags: `{ locked=true, repeating=true, mouse=true, on_release=true }`

## Globals Pattern

Every module that needs shared variables does `local G = require("globals")`. Do not use bare globals — add new shared values to `globals.lua` and access via `G.*`.

## Hardware Context

- **GPU**: NVIDIA — hardware cursors off, direct_scanout off, GBM/GLX env forced
- **Monitor 1** (DP-2): MSI MP275Q 2560x1440@100Hz, position 0x0, 10-bit, sdrMax=200 nits
- **Monitor 2** (eDP-2): AU Optronics laptop 1920x1200@165Hz, position 2560x0, 10-bit, sdrMax=80 nits
- Cursor theme: `peachy_cursor` size 12
- Input method: fcitx5 (Wayland-native)
- Wallpaper daemon: `awww` (not swww)
- Screen shader: `hyprshade on vibrance` applied on every reload

## Visual Theme

Dark Japanese Y2K gothic (黑暗少女感). Key values in `ui/theme.lua`:
- Active border: blood red → electric purple gradient, 45°
- Inactive border: deep vampire crimson
- `rounding = 4`, `rounding_power = 3` (squircle — 方框感)
- Shadow: diffused blood-red glow
- Animation curves: `yuki` (snappy), `silk` (smooth fade), `flash` (instant exit)

To change color theme: edit only the `C` table in `ui/theme.lua`.

## Known Uncertainty

`hl.submap_bind` function name is inferred — verify against [Hyprland wiki submaps](https://wiki.hypr.land/Configuring/Basics/Submaps/) if `binds/submaps.lua` errors on reload. The dispatcher for resize-by (`hl.dsp.window.resize_by`) may also need name verification.
